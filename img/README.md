# Images (not included)

Jules works without these files, but they're what make it cinematic. Put them in this folder.

Each photo or painting used by the film also needs a matching depth map: a greyscale PNG where white is near and black is far.

## In the app

| Where | Images |
|---|---|
| Home's header (click the small `01 / 06` counter to cycle through them) | `hero.jpg`, `space.jpg`, `launch-tower.jpg`, `n1.jpg`, `engines.jpg`, `tower.jpg` |
| The "Launch film" card in the sidebar | `space.jpg` |

If an image is missing, Home falls back to a dark gradient.

## In the film

| Scene | Image | Depth map |
|---|---|---|
| Launch | `hero.jpg`, `launch-tower.jpg`, `launch-sls.jpg`, `wall-tower.jpg` | `hero-depth.png`, `launch-tower-depth.png`, `launch-sls-depth.png`, `wall-tower-depth.png` |
| The rocket | `rocket.png` (a cut-out with transparency) | none |
| Engines | `engines.jpg`, `steel.jpg` | `engines-depth.png`, `steel-depth.png` |
| Body | `steel.jpg`, `tower.jpg` | `steel-depth.png`, `tower-depth.png` |
| The star | `space.jpg`, `n1.jpg`, `wall-space.jpg` | `space-depth.png`, `n1-depth.png`, `wall-space-depth.png` |

## Using images publicly

For anything public, use images you own or ones that are free to use. NASA's image library (images.nasa.gov) is a good source of launch photos.
